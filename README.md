# Quote Stream

A single idea at a time.

**Live:** https://nmpy7knjd8-code.github.io/quote-stream/

Tap the quote (or the small chevron) to expand an explanation and further reading. → / Space for next, Enter to expand.

`quotes.json` schema: `[{quote, author, work, expansion: [paragraphs] | "markdown", sources: [{title, author, url}]}]`
